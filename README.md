# Matrix Shapes — 3D-фигуры для проектора (Android TV)

Вращающиеся каркасные фигуры на чёрном фоне. Приложение для Xiaomi TV Box и других Android TV.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `app/assets/index.html` | **Вся графика и логика**: фигуры, цвета, движение, управление с пульта. Почти все правки делаются здесь. |
| `app/src/com/matrixshapes/MainActivity.java` | Оболочка Android: полноэкранный WebView, экран не гаснет, кнопки пульта передаются странице. |
| `app/AndroidManifest.xml` | Название, версия, иконка на главном экране Android TV. |
| `app/res/drawable/icon.xml`, `banner.xml` | Иконка и баннер (векторные). |
| `app/res/values/strings.xml` | Название приложения. |
| `build.sh` | Сборка APK без Android Studio и Gradle. |
| `debug.keystore` | Ключ подписи (в git не хранится, только локально — сделайте резервную копию). **Не удаляйте**: без него новую версию нельзя будет поставить поверх старой (придётся удалять приложение, настройки сбросятся). |
| `matrixshapes.apk` | Последний собранный APK. |

## Частые правки в `index.html`

- **Добавить фигуру** — массив `SHAPES`. Каждая фигура это `{ name, frame(t) }`, где `frame` возвращает
  `{ pts: [[x,y,z], ...], edges: [[i,j], ...] }`. Координаты примерно от −1.3 до 1.3.
  Дополнительные флаги: `ortho` (без перспективы, для иллюзий), `dots` (точки вместо линий),
  `rotY` + `tilt` (вращение только вокруг вертикальной оси), `slow` (множитель скорости вращения).
- **Цвета** — массив `PALETTES` (RGB).
- **Толщина линий** — в `render()`: `const lw = Math.max(1, S / 90 * ...)`. Меньше делитель — толще линии.
- **Траектория полёта** (динамический режим) — в `render()`, строки с `cx =` и `cy =`.
- **Отступ от краёв экрана** — `keepOnScreen()`, переменная `m`.
- **Кнопки пульта** — обработчик `addEventListener('keydown', ...)` в конце файла.

Проверить изменения можно прямо на компьютере: открыть `app/assets/index.html` в Chrome
(стрелки и Enter на клавиатуре работают как пульт).

## Сборка и установка на бокс

Нужно (уже установлено на этом компьютере):
- JDK 17 — `C:\Program Files\Java\jdk-17`
- Android SDK (build-tools 34, platform android-34) — `%LOCALAPPDATA%\Android\Sdk`
- adb — `%LOCALAPPDATA%\Android\platform-tools\adb.exe`

В Git Bash из папки проекта:

```bash
./build.sh
```

```bash
ADB="$LOCALAPPDATA/Android/platform-tools/adb.exe"; "$ADB" connect 192.168.1.18:5555 && "$ADB" install -r matrixshapes.apk
```

```bash
"$LOCALAPPDATA/Android/platform-tools/adb.exe" shell am start -S -n com.matrixshapes/.MainActivity
```

Если бокс не подключается: на боксе должна быть включена «Отладка по сети» (Настройки → Для разработчиков),
а IP мог смениться — посмотрите его в настройках сети бокса.

## Управление с пульта

- ◀ ▶ — сменить фигуру
- ▲ ▼ — изменить выбранный параметр (по умолчанию размер)
- OK — что меняют ▲ ▼: размер → скорость → цвет → режим (летает / стоит) → положение (только в статическом режиме)
- 1–4 — цвет
- Назад — выход

Все настройки запоминаются.
